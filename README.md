**A real-time website uptime monitoring platform.**

## Overview

Pulse is an uptime monitoring platform that periodically monitors website availability, tracks response times, and provides real-time service health insights through a centralized status dashboard.

## Tech Stack

- **Backend:** Python, DRF, Django Channels
- **Background Jobs:** Celery, Redis
- **Database:** PostgreSQL, TimescaleDB
- **Frontend:** React, TypeScript, Apache ECharts
- **Infrastructure:** Docker, Kubernetes, Helm
- **CI/CD:** GitHub Actions
